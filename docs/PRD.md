# MeowHealth Web 需求说明书 (PRD)

## 1. 产品概述
MeowHealth Web 是 iOS 版 "猫咪健康守护" 的跨平台延伸。旨在提供一个支持桌面端与移动端浏览器访问的私有化单用户系统，保留核心的健康追踪和 AI 辅助功能。

## 2. 核心目标功能
1. **猫咪档案管理**
   - 基础信息记录（品种、生日、性别、体重等）。
   - 头像与相册管理。
2. **健康记录流水**
   - 体重趋势记录（对应 iOS 的 SwiftCharts 体重趋势图）。
   - 疫苗、驱虫记录与提醒设置。
   - 异常症状记录（呕吐、腹泻等）。
3. **AI 化验单分析 (核心亮点)**
   - 支持多图片/PDF上传化验单。
   - 集成 Gemini API 进行 OCR 与指标解读。
   - 结构化存储历史报告，支持对比查看。
4. **Dashboard 概览**
   - 待办事项提醒（对应 iOS 的 UNNotificationManager 提醒逻辑）。
   - 近期健康状况摘要。

## 3. 非功能性需求
- **部署方式**：单用户私有化部署（Docker 推荐）。
- **响应式设计**：完美适配 PC 宽屏及手机竖屏。
- **安全性**：基础的密码/Token 访问控制（防止部署在公网被非授权访问）。
