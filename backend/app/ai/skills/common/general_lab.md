# 通用化验指标参考指南 (General Lab Standards)

## 1. 肾功能 (Kidney Function)
- **CREA (肌酐) / BUN (尿素氮) / SDMA**: 
  - **偏高**: 提示肾脏代谢功能下降，可能患有慢性/急性肾病。
  - **偏低**: 通常无临床病理意义，或可能因肌肉量过少导致。

## 2. 肝功能 (Liver Function)
- **ALT (谷丙转氨酶) / AST (谷草转氨酶) / TBIL (总胆红素)**: 
  - **偏高**: 提示肝细胞受损、肝胆系统炎症或梗阻。

## 3. 血常规 (CBC)
- **WBC (白细胞总数) / NEU (中性粒细胞)**: 
  - **偏高**: 提示体内存在细菌感染、炎症或剧烈应激反应。
  - **偏低**: 提示病毒感染（如猫瘟）或免疫力低下。
- **RBC (红细胞) / HGB (血红蛋白) / HCT (红细胞压积)**:
  - **偏低**: 提示贫血（可能因营养不良、失血、寄生虫或慢性肾病导致）。

## 4. 血糖与胰腺 (Glucose & Pancreas)
- **GLU (血糖)**: 
  - **偏高**: 应激反应，或可能为糖尿病，需结合果糖胺确诊。
  - **偏低**: 低血糖，需防休克。
- **fPL (猫胰脂肪酶)**: 
  - **偏高**: 提示胰腺炎。
