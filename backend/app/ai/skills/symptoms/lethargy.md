# 精神萎靡 (Lethargy) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 感染/发热 | 精神差+体温升高 | 任何年龄段 |
| 贫血 | 精神差+黏膜苍白 | 牙龈发白、HCT降低 |
| 慢性肾病 | 精神差+多饮多尿 | 老年猫 |
| 糖尿病/甲亢 | 精神差+多食消瘦 | 体重下降明显 |
| 心脏病 | 精神差+呼吸急促 | HCM、肺水肿 |
| 低血糖 | 精神差+虚弱+抽搐 | 幼猫、糖尿病患者 |
| 中毒 | 精神差+呕吐/抽搐 | 接触史 |
| 疼痛 | 精神差+躲藏/弓背 | 外伤、胰腺炎、尿闭 |

## 危险信号
- 完全不动、对刺激无反应
- 呼吸急促/困难
- 黏膜苍白或发黄
- 体温过低（<37°C）

## 建议检查
- 血常规（排查感染、贫血）
- 生化（排查肾病、肝病、糖尿病）
- 体温测量
- 腹部触诊
