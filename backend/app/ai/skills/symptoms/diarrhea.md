# 腹泻 (Diarrhea) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 饮食不当 | 急性腹泻、无发热 | 换粮、偷吃、应激 |
| 寄生虫 | 软便/黏液便 | 未驱虫、户外活动 |
| 炎症性肠病 (IBD) | 慢性反复腹泻 | 中老年、体重下降 |
| 猫瘟 | 水样/血便+高热 | 幼猫、未接种疫苗 |
| 肠道淋巴瘤 | 慢性腹泻+消瘦 | 老年猫、腹部肿块 |
| 甲状腺功能亢进 | 腹泻+多食消瘦 | 老年猫、心跳快 |
| 胰腺外分泌不足 (EPI) | 脂肪泻、恶臭 | 稀便含未消化脂肪 |

## 危险信号
- 血便/黑便（消化道出血）
- 腹泻伴高热、精神萎靡
- 持续超过 3 天
- 幼猫腹泻（脱水风险高）

## 建议检查
- 粪检：寄生虫卵、细菌培养
- 血常规、生化
- 腹部超声
- 肠道活检（慢性/不明原因时）
