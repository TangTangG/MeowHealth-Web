# 跛行/疼痛 (Lameness/Pain) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 外伤 | 突发跛行+肿胀/出血 | 坠楼、车祸、打架 |
| 关节炎 | 慢性跛行+活动减少 | 老年猫、肥胖 |
| 髋关节发育不良 | 后肢跛行+不愿跳 | 大型猫、幼猫 |
| 血栓栓塞 (ATE) | 后肢瘫痪+冰冷+疼痛嚎叫 | HCM 患者、突发 |
| 骨折 | 无法负重+异常活动 | X光确诊 |
| 软组织损伤 | 轻度跛行+肿胀 | 扭伤、拉伤 |
| 指甲/趾间炎 | 舔脚+跛行 | 指甲断裂、异物刺入 |

## 危险信号
- 后肢瘫痪 + 疼痛嚎叫（血栓栓塞！急诊！）
- 开放性骨折
- 大量出血
- 坠楼后（即使表面正常也需排查内伤）

## 建议检查
- X光（骨折/关节）
- 心脏超声（排查 ATE 来源）
- 触诊/神经学检查
- 血液检查（排查感染、炎症）
