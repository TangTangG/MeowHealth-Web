# 食欲下降/拒食 (Anorexia) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 急性肠胃炎 | 拒食+呕吐/腹泻 | 饮食不当、应激 |
| 猫瘟 | 拒食+高热+呕吐 | 幼猫、未接种疫苗 |
| 脂肪肝 (HL) | 拒食→黄疸→虚弱 | 肥胖猫、应激后 |
| 口腔疾病 | 拒食+流口水+口臭 | 口炎、牙周炎、异物 |
| 肾脏疾病 | 拒食+多饮多尿 | 老年猫 |
| 胰腺炎 | 拒食+腹痛+弓背 | 突发 |
| 异物梗阻 | 拒食+呕吐+腹痛 | 有异食史 |
| 应激 | 拒食+躲藏 | 环境变化、新成员 |

## 危险信号
- 完全拒食超过 24 小时（猫极易继发脂肪肝）
- 拒食伴黄疸
- 拒食伴腹部剧痛
- 拒食伴呼吸困难

## 建议检查
- 口腔检查
- 血常规、生化
- 腹部超声
- 猫瘟抗原（幼猫）
