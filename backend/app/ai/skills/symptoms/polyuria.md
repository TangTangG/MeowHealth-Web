# 多饮多尿 (Polyuria/Polydipsia) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 慢性肾病 (CKD) | 多饮多尿+体重下降 | 老年猫、口臭 |
| 糖尿病 | 多饮多尿+多食消瘦 | 肥胖猫、果糖胺升高 |
| 甲状腺功能亢进 | 多饮+多食消瘦+亢奋 | 老年猫、心跳快 |
| 子宫蓄脓（母猫） | 多饮多尿+腹部膨大 | 未绝育母猫、外阴分泌物 |
| 肝功能障碍 | 多饮+黄疸+腹水 | 腹部触诊肝肿大 |
| 高钙血症 | 多饮+食欲下降 | 淋巴瘤、维生素D中毒 |
| 尿崩症 | 极度多饮多尿 | 罕见、其他检查正常 |

## 危险信号
- 尿量骤增伴精神萎靡
- 完全拒食
- 腹部异常膨大

## 建议检查
- 生化：肌酐、血糖、T4、血钙
- SDMA（早期肾病）
- 尿常规：尿糖、尿比重
- 腹部超声
