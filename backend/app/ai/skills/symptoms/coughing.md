# 咳嗽/打喷嚏 (Coughing/Sneezing) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 猫鼻支 (FHV) | 打喷嚏+流泪+流涕 | 终身潜伏、应激复发 |
| 上呼吸道感染 | 打喷嚏+咳嗽+低烧 | 细菌/病毒 |
| 哮喘/过敏 | 咳嗽+呼吸急促 | 季节性、环境过敏原 |
| 心脏病 (HCM) | 呼吸急促+咳嗽 | 老年猫、品种倾向 |
| 胸腔积液 | 呼吸急促+腹式呼吸 | FIP、心衰、肿瘤 |
| 异物 | 突发剧烈咳嗽 | 吸入草、玩具碎片 |
| 肺癌/肿瘤 | 慢性咳嗽+消瘦 | 中老年、X光占位 |

## 危险信号
- 张口呼吸/极度呼吸困难
- 口唇发紫（缺氧）
- 呼吸频率 >40次/分钟（静息状态）
- 咳嗽伴血痰

## 建议检查
- 血常规
- 胸片/X光
- 心脏超声（排查 HCM）
- PCR 检测（FHV/FCV）
