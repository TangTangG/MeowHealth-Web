# 呕吐 (Vomiting) 鉴别诊断

## 常见原因（按优先级排序）

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 毛球症 | 干呕后吐毛球 | 长毛猫、季节性换毛 |
| 急性肠胃炎 | 呕吐+腹泻 | 饮食不当、应激 |
| 猫瘟 | 频繁呕吐+拒食+发热 | 幼猫、未接种疫苗 |
| 异物梗阻 | 呕吐+腹部疼痛 | 有异食史 |
| 慢性肾病 | 呕吐+多饮多尿 | 老年猫 |
| 脂肪肝 | 呕吐+黄疸+拒食 | 肥胖猫绝食后 |
| 胰腺炎 | 呕吐+腹痛+弓背 | 突发、严重时休克 |
| 甲亢 | 呕吐+多食消瘦 | 老年猫、心跳快 |

## 危险信号（需立即就医）
- 呕吐物带血（咖啡渣样 = 上消化道出血）
- 呕吐伴随精神极度萎靡
- 频繁呕吐（>3次/天）无法进水
- 异物/毒素摄入史

## 建议检查
- 基础：血常规、生化、腹部触诊
- 进阶：腹部超声、X光（排查异物/梗阻）
- 专项：fPL（胰腺炎）、T4（甲亢）
