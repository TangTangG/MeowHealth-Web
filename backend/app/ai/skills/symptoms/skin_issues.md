# 皮肤问题 (Skin Issues) 鉴别诊断

## 常见原因

| 疾病 | 特征 | 鉴别要点 |
|------|------|----------|
| 猫癣（皮肤真菌） | 圆形脱毛+皮屑+红疹 | 人畜共患、伍德氏灯 |
| 跳蚤过敏 | 腰背部脱毛+小红点 | 跳蚤粪便（黑色颗粒） |
| 螨虫（疥螨/耳螨） | 剧烈瘙痒+脱毛 | 耳螨=耳垢+甩头 |
| 过敏性皮炎 | 瘙痒+舔腹/四肢 | 食物/环境过敏 |
| 细菌感染 | 脓疱+结痂+红肿 | 继发感染 |
| 脂溢性皮炎 | 油腻+皮屑+异味 | 原发或继发 |
| 精神性脱毛 | 对称性脱毛+皮肤正常 | 过度舔舐、应激 |
| 肿瘤 | 皮下肿块+溃疡 | 中老年、生长快 |

## 危险信号
- 迅速扩散的脱毛/红斑
- 溃疡不愈合
- 全身性皮疹
- 伴随发热/精神差

## 建议检查
- 伍德氏灯（猫癣初筛）
- 皮肤刮片/镜检（螨虫/真菌）
- 真菌培养（确诊猫癣）
- 皮肤活检（不明原因/疑似肿瘤）
